# Housing type mix as a lever for sustainable urban mobility

This repository contains data and code used in an investigation of the role of housing type share as a factor influencing several sustainabile mobility outcomes, as described in the research article
"Housing type mix as a lever for sustainable urban mobility" published in Transportation Research Part D in 2026, article number 105646.

The repository contains one csv file which is the basis of the investigation, and one python notebook containing the entire analysis. 

Readers interested in the data sources can consult the research article, and/or contact the author at p.berrill@cml.leidenuniv.nl
